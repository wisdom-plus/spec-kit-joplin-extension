# Quickstart: Kindle Highlights Import

## Purpose
Load Kindle highlights into Joplin notes using the extension.

## Prerequisites
- Joplin Desktop installed
- Amazon account with Kindle highlights available

## Quickstart (Developer)

1. Install dependencies
2. Build the extension
3. Open Joplin Desktop and enable Development Mode
4. Load the extension from the local build output
5. Run an import for a selected book

## Quickstart (User)

1. Install the extension in Joplin Desktop
2. Open the extension panel
3. Log in to Amazon within the embedded login view
4. Select a book and choose the target note
5. Start the import and review the created note

## Validation Checklist
- Import completes without UI freeze
- New note per book is created by default
- No duplicate highlights on repeated import
